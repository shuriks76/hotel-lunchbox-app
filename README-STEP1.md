# Шаг 1: каркас проекта + вход/регистрация

## Что сделано
- Next.js 14 (App Router, TypeScript) + Tailwind, без `src/`.
- i18n на 4 языка (`en`, `da`, `uk`, `ru`) через `next-intl`, с
  автоопределением языка браузера при первом визите
  (`localePrefix: 'always'` — в адресе всегда есть `/ru/...` и т.п.).
- Supabase-клиенты: для браузера (`lib/supabase/client.ts`), для
  серверных компонентов (`lib/supabase/server.ts`) и для middleware
  (`lib/supabase/middleware.ts`, обновляет сессию на каждый запрос).
- Экран `/[locale]/login` — email/пароль (вход и регистрация, с
  переключателем) + кнопка "Continue with Google" через Supabase OAuth.
- `/auth/callback` — обмен OAuth-кода на сессию.
- Дизайн-токены в `app/globals.css` + `tailwind.config.ts` — цвета сняты
  пиксельно с присланного скриншота тёмной темы (фон `#0F172A`, карточки
  `#1E293B`, золото `~#C89632`, зелёный статус `#4ADE80`). Светлая тема
  подобрана в той же стилистике — экрана-референса для неё не было,
  можно будет поправить, когда увидим вживую.
- Шрифты через `next/font/google`: Cormorant Garamond (заголовки/лого,
  `font-display`) + Inter (интерфейс, `font-sans`).
- Логотипы: `public/logo/profil-hotels-logo-transparent.png` (для тёмной
  темы — у присланного файла реально есть альфа-канал, проверил) и
  `public/logo/profil-hotels-logo-white-bg.png` (для светлой темы и
  будущей печатной формы/PDF).
- Favicon/app-иконки (`app/icon.png`, `app/apple-icon.png`,
  `public/favicon-*.png`) — **важно**: у нас не было отдельного файла
  только со знаком «P» (в ТЗ он упоминается как `profil-hotels-mark.png`),
  поэтому я автоматически вырезал знак из полного логотипа. Получилось
  прилично, но не идеально ровно — если у вас где-то есть чистый файл
  только со знаком, лучше потом заменить `public/favicon-*.png`,
  `app/icon.png`, `app/apple-icon.png` на него.

## Как запустить у себя

```bash
npm install
cp .env.local.example .env.local
# впишите в .env.local:
#   NEXT_PUBLIC_SUPABASE_URL      — Supabase: Settings -> API -> Project URL
#   NEXT_PUBLIC_SUPABASE_ANON_KEY — Supabase: Settings -> API -> anon public key
npm run dev
```

Откройте http://localhost:3000 — должно само редиректнуть на
`/ru/login` (или `/en/login`, в зависимости от языка браузера).

## Если что-то не заработает
Скорее всего, зацепится что-то из следующего (нормально для первого
прогона без возможности потестировать у меня локально):
- Версии пакетов — если `npm install` ругается на peer deps, пришлите
  текст ошибки, поправим версии.
- Middleware — сочетание next-intl + Supabase middleware я не мог
  прогнать вживую, если после логина редирект зациклится или cookies
  не проставятся — пришлите, что видите в консоли/Network, разберём.

Пришлите, что получилось (или текст ошибки) — и идём дальше, к экрану
"ждите заселения" и главному экрану с календарём.
